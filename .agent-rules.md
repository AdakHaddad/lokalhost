# Agent Rules

- **Package Manager:** Always use `bun` (and `bunx`). Run commands from root using `bun --bun run <script>`.
- **Database/Backend (Current Phase):** Build completely offline first. Use local mock DB (in-memory or LocalStorage) and `faker` for data generation to mimic Supabase schema. Do not connect to real Supabase until explicitly requested.
- **UI Framework:** Use `shadcn/ui` components and Tailwind CSS.
- **Workflow:** Act autonomously. Take a bet and proceed if stuck. Avoid asking human for input unless choosing a major project name or extreme ambiguity. Update documentation (`ROADMAP.md`, `ACTIVE_CONTEXT.md`) as development progresses.
