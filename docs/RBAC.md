# Role-Based Access Control

Strict hierarchical scope.
Scope = Geographic/Admin unit (e.g., RT, Dukuh, Kecamatan).

Roles: `platform_admin`, `organization_admin`, `kecamatan_admin`, `village_admin`, `dukuh_admin`, `rw_admin`, `rt_admin`, `resident`.

Rule: Higher scope != unrestricted sensitive data access. Explicit visibility policies required.
